# Prince Kyle Ortiz

A one-page student site for Prince Kyle Ortiz, 18, from Tanza, Cavite, Philippines. He studies at Granby College of Science and Technology.

## Run

```bash
npm install
npm run dev
```

The dev server listens on [http://127.0.0.1:5173](http://127.0.0.1:5173).

```bash
npm run build
npm run preview
```
